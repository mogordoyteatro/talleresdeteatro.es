## Convención para fotos de sesión (PXL_*)

Las fotos tomadas con teléfono durante clases siguen el patrón `PXL_YYYYMMDD_HHMMSS...`. Se mapean así:

```
PXL_YYYYMMDD_* → clase-teatro-barcelona-[MES]-[AÑO]-sesion-[N]-[NNN].webp
```

Donde `[NNN]` es un número secuencial con ceros a la izquierda (001, 002…) dentro de cada sesión.
